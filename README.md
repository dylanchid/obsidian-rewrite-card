# Rewrite Card

Draft a rewrite beside selected text without changing the original until you apply it.

## Use

Select text in a Markdown note and run **Rewrite selected text in card** from the command palette. Edit the draft in the card, then apply it to replace the selection or close the card to keep the original text. Check the selected range before applying a rewrite if you have edited the note since opening the card.

## Install manually

Run `npm ci && npm run build`, then copy `manifest.json`, `main.js`, and `styles.css` into `<vault>/.obsidian/plugins/rewrite-card/`. Enable the plugin under **Settings → Community plugins**.

## Develop

Run `npm ci` and `npm run build` from this directory.
